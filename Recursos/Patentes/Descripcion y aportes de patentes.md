#  Patentes Relacionadas

##  Descripción general
Esta sección reúne patentes relacionadas con sistemas de asistencia para personas con discapacidad visual, incluyendo dispositivos ópticos, hápticos y sistemas de detección de peatones mediante visión por computadora. Estas tecnologías sirven como base para el desarrollo de soluciones de movilidad segura y accesible.

---

## 1. Módulo óptico para semáforos peatonales con indicación acústica
**Descripción:** Dispositivo diseñado para semáforos peatonales que incorpora señales acústicas para asistir a personas con discapacidad visual durante el cruce de calles.  
**Aporte:** Mejora la accesibilidad urbana al integrar señales auditivas que complementan la información visual del semáforo, facilitando la orientación segura de peatones con discapacidad visual.

🔗 https://worldwide.espacenet.com/patent/search/family/043447627/publication/ES1073627U

---

## 2. Sistema y método para la detección de peatones mediante procesamiento de imágenes
**Descripción:** Sistema basado en visión por computadora que detecta peatones en entornos urbanos mediante procesamiento de imágenes.  
**Aporte:** Proporciona una base tecnológica para sistemas inteligentes de asistencia y seguridad vial, permitiendo identificar peatones en tiempo real para evitar accidentes.

🔗 https://worldwide.espacenet.com/patent/search/family/078706485/publication/US2021369545A1

---

## 3. Dispositivo háptico vibratorio para personas con discapacidad visual
**Descripción:** Dispositivo portátil que utiliza vibraciones hápticas para comunicar información al usuario con discapacidad visual.  
**Aporte:** Ofrece una alternativa sensorial no visual para la comunicación de información espacial o de alerta, mejorando la autonomía del usuario en entornos desconocidos.

🔗 https://patents.google.com/patent/US10719707B2/en
