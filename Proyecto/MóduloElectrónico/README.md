# Esquemáticos

Contiene los esquemáticos electrónicos del proyecto SafeWalk AI, elaborados por el Grupo 08 de Fundamentos de Diseño (UPCH).

* **Esquematico\_VFinal\_DISEÑO.pdf** — Esquemático versión final. Incluye todos los módulos del sistema: sensor de distancia (VL53L1X), módulo principal (XIAO ESP32-S3), sensor de presencia (LD2410C), alerta sonora (PAM8403 + altavoz), reproductor de audio (DFPlayer Mini), LED indicador y módulo de carga (TP4056 + LiPo + XL6009 boost converter).
* **Esquema\_electronico\_E08.pdf** — Esquemático versión E08. Contiene los mismos módulos funcionales que la versión final, sin el módulo de carga ni el reproductor de audio.
