# Informe Técnico de Proyecto: Control de Servomotor mediante Bluetooth con ESP32

---

## 1. Introducción
El presente informe detalla el procedimiento de diseño, configuración e implementación de un sistema de control inalámbrico para un servomotor de rango extendido (0° a 270°) utilizando el microcontrolador ESP32 y una aplicación móvil personalizada desarrollada en la plataforma MIT App Inventor. La comunicación entre ambos dispositivos se realiza mediante el protocolo Bluetooth Clásico.

---

## 2. Componentes Utilizados
* **Microcontrolador:** ESP32 (NodeMCU-32S o equivalente).
* **Actuador:** Servomotor de rango extendido (0° - 270°).
* **Software de Desarrollo:** Arduino IDE.
* **Plataforma de Aplicación Móvil:** MIT App Inventor.
* **Conectividad:** Bluetooth Clásico integrado en el chip ESP32.
* **Cableado:** Cables jumper (Macho-Hembra / Macho-Macho) y cable de datos Micro-USB.

---

## 3. Conexiones Físicas (Hardware)
El circuito se estructuró conectando el servomotor directamente a la placa ESP32, alimentándose a través del voltaje provisto por el puerto USB (5V) de la siguiente manera:

| Cable del Servomotor | Función | Pin en el ESP32 |
| :--- | :--- | :--- |
| **Negro** | Tierra (GND) | GND |
| **Rojo** | Alimentación (VCC) | VIN / 5V |
| **Blanco** | Señal de Control (PWM) | GPIO 18 (D18) |

---

## 4. Desarrollo de la Aplicación Móvil (MIT App Inventor)

### 4.1 Componentes de la Interfaz
Se dispuso una interfaz minimalista y funcional compuesta por:
1.  **ListPicker (Selector de Lista):** Renombrado como `Conectar_Bluetooth`. Filtra y muestra los dispositivos Bluetooth vinculados en el smartphone.
2.  **Label (Etiqueta):** Renombrada como `Ángulo`. Muestra en pantalla el valor entero del ángulo actual seleccionado.
3.  **Slider (Deslizador):** Configurado con un valor mínimo (`MinValue`) de **0** y un valor máximo (`MaxValue`) de **270** para ajustarse al límite físico del motor.
4.  **BluetoothClient1:** Componente no visible encargado de la gestión del canal de comunicación inalámbrica.

### 4.2 Lógica de Bloques Utilizada
* **Antes de la Selección (`BeforePicking`):** Se cargan en el `ListPicker` las direcciones y nombres de los dispositivos emparejados en el sistema del celular.
* **Después de la Selección (`AfterPicking`):** Se efectúa la llamada de conexión hacia la dirección MAC del dispositivo seleccionado a través de un bloque puente `evaluate but ignore result` para mitigar restricciones de tipo de datos de algunas versiones de la plataforma.
* **Cambio de Posición del Slider (`PositionChanged`):** Al desplazar el control, el valor flotante se procesa mediante la función matemática `round` para obtener un número entero. Este entero es visualizado en la etiqueta de texto y se envía mediante `.SendText` concatenado con un caracter de escape de nueva línea (`\n`) para actuar como delimitador de mensajes.

---

## 5. Código Fuente Definitivo (Firmware ESP32)

El código implementado en el lenguaje de Arduino utiliza la librería nativa para la emulación del puerto serie por Bluetooth y la librería especializada `ESP32Servo` para la gestión precisa de los pulsos PWM sobre la arquitectura del procesador.

```cpp
#include "BluetoothSerial.h"
#include <ESP32Servo.h>

// Instancia para el control del Bluetooth y del Servomotor
BluetoothSerial ESP_BT;
Servo miServo;

// Definición de constantes del hardware
const int pinServo = 18; 

void setup() {
  // Inicialización del puerto serie físico para depuración técnica
  Serial.begin(115200);
  
  // Inicialización del módulo Bluetooth con el identificador de red
  ESP_BT.begin("Prueba_ESP32"); 
  Serial.println("Dispositivo listo con control de Servo (Rango: 0-270).");

  // Configuración de temporizadores internos de la librería ESP32Servo
  ESP32PWM::allocateTimer(0);          
  miServo.setPeriodHertz(50); // Frecuencia de actualización estándar para servos (50Hz)
  
  // Acoplamiento del pin con los anchos de pulso en microsegundos mínimos y máximos
  // Ajustados para cubrir el espectro angular completo de 270 grados
  miServo.attach(pinServo, 500, 2500); 
  
  // Posicionamiento inicial de seguridad
  miServo.write(0); 
}

void loop() {
  // Verificación de bytes disponibles en el buffer del módulo Bluetooth
  if (ESP_BT.available()) {
    
    // Lectura de la cadena de texto entrante hasta encontrar el delimitador '\n'
    String datosRecibidos = ESP_BT.readStringUntil('\n');
    datosRecibidos.trim(); // Eliminación de espacios en blanco o caracteres basura

    // Validación de consistencia del dato extraído
    if (datosRecibidos.length() > 0) {
      int angulo = datosRecibidos.toInt(); // Conversión de la cadena de texto a entero

      // Control de límites lógicos para proteger los engranajes del motor
      if (angulo >= 0 && angulo <= 270) {
        miServo.write(angulo); // Escritura de la posición angular en el actuador
        
        // Retroalimentación visual en el terminal de la computadora
        Serial.print("Moviendo servo a: ");
        Serial.print(angulo);
        Serial.println(" grados.");
      }
    }
  }
  delay(10); // Retraso de cortesía para estabilizar las tareas de fondo del procesador
}

## 6. Procedimiento de Carga y Pruebas
1. **Instalación de Librerías:** Desde el gestor de tarjetas del Arduino IDE se integró la librería `ESP32Servo` de Kevin Harrington, solventando el error de compilación por falta de dependencias.
2. **Carga del Firmware (Bootloader):** Durante el proceso de compilación y subida, ante la secuencia de conexión (`Connecting......`), se hizo uso del bypass de hardware presionando el botón físico **BOOT** integrado en el ESP32 para permitir la escritura en la memoria Flash.
3. **Sincronización:** Se habilitó el servicio de Bluetooth y Localización en el terminal Android, vinculando exitosamente el dispositivo bajo el nombre de `Prueba_ESP32`.
4. **Prueba de la Aplicación:** Se desplegó la interfaz mediante *MIT AI2 Companion*, efectuando la conexión y verificando la transmisión asíncrona de datos tanto en la pantalla del móvil (actualización del Label) como en el Monitor Serie a una tasa de transferencia de `115200` baudios.

---

## 7. Conclusiones
El proyecto cumple exitosamente con los objetivos planteados. El uso del delimitador `\n` garantiza que el ESP32 segmente de manera asíncrona y exacta las cadenas de caracteres entrantes por el flujo serie inalámbrico, evitando el encolamiento de datos erróneos. El ajuste de los tiempos de ancho de pulso en microsegundos (`500` a `2500` µs) en la función `attach` permitió aprovechar el torque y el recorrido completo de los 270° del servomotor de manera lineal y fluida con respecto al deslizador de la aplicación móvil.
